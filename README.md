# Каприз — кофейня рядом с домом

Адаптивный концептуальный сайт небольшой кофейни: меню с выбором объёма кофе, галерея и условная карта.

HTML, CSS и JavaScript без сборки. Для локального просмотра откройте index.html или запустите `python -m http.server 8080`.

Учебный портфолио-проект. Бренд, адрес, телефон и ассортимент — демонстрационные. Изображения предоставлены для проекта.
